# תיאור התוכנית

התוכנית מאפשרת לבחור קבצי שמע או תיקייה המכילה קבצי שמע.

## מה התוכנית עושה

1.  קוראת את שם הקובץ.
2.  ממירה את שם הקובץ לדיבור בעברית באמצעות gTTS.
3.  יוצרת קובץ הקדמה קולי.
4.  מחברת את ההקדמה לתחילת קובץ השמע המקורי.
5.  שומרת את התוצאה כקובץ MP3 חדש בתיקייה `processed_audio`.

## ספריות עיקריות

-   os -- עבודה עם קבצים ותיקיות.
-   tkinter -- ממשק גרפי.
-   gTTS -- המרת טקסט לדיבור.
-   pydub -- עיבוד וחיבור קבצי שמע.

## קבצים נתמכים

-   MP3
-   WAV
-   OGG
-   FLAC
-   AAC

## ממשק המשתמש

-   כפתור לבחירת קבצים.
-   כפתור לבחירת תיקייה.
-   הודעת סיום לאחר עיבוד כל הקבצים.
